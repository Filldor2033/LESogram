## 📖 Описание проекта

**LESogram** — это современный веб-чат с открытым исходным кодом: асинхронный бэкенд на **FastAPI** и реактивный фронтенд на **Svelte 5 + TypeScript**. Проект создан как полнофункциональное решение для общения в реальном времени с акцентом на безопасность, производительность и удобство использования — от десктопа до смартфона.

### 🎯 Цели проекта

- **Простота развёртывания** — запускается одной командой, не требует сложной настройки
- **Безопасность** — многоуровневая защита данных и файлов пользователей
- **Производительность** — асинхронный бэкенд на FastAPI и лёгкий реактивный фронтенд
- **Кроссплатформенность** — адаптивный интерфейс для десктопа и мобильных устройств
- **Расширяемость** — модульная архитектура позволяет легко добавлять новый функционал

### 🔄 Поток данных

1. **Аутентификация** → Пользователь регистрируется/входит → получает JWT `access_token`
2. **Комнаты** → Создаёт или присоединяется к комнате → получает `room_token`
3. **Чат** → Устанавливает WebSocket-соединение → отправляет и получает сообщения, реакции, статусы набора текста
4. **Файлы** → Загружает через HTTP с прогресс-баром → получает подтверждение и URL для скачивания

### 🌟 Ключевые особенности

#### 🔐 Двухуровневая аутентификация

- **Access Token** — для доступа к API (регистрация, комнаты, профиль), живёт 24 часа
- **Room Token** — для доступа к конкретной комнате (чат, история, файлы)
- Токены подписываются с использованием HS256

#### 💬 Реальное время без задержек

- WebSocket-соединение для мгновенной доставки сообщений
- Индикатор «печатает…» в реальном времени
- Системные уведомления о входе/выходе пользователей
- Уведомления об упоминаниях (@username)
- Heartbeat-механизм (пинг каждые 25с, отключение зависших соединений после 75с)
- Очистка «мёртвых» соединений

#### 💬 Богатая работа с сообщениями

- **Реакции** — 6 эмодзи-реакций на любое сообщение (👍 ❤️ 😂 😮 😢 🔥)
- **Ответы** — цитирование сообщения с превью оригинала
- **Редактирование** — автор может изменить своё сообщение (с пометкой «изменено»)
- **Упоминания** — @username с автодополнением и уведомлением адресата
- **Удаление** — администраторы могут удалять любые сообщения

#### 🛡️ Многоуровневая защита файлов

- **Белые списки** — разрешены только безопасные типы (изображения, видео, аудио, документы)
- **Чёрные списки** — запрещены исполняемые файлы, скрипты, HTML
- **Валидация** — проверка MIME-типа и расширения файла
- **Сохранение** — случайные имена файлов для предотвращения атак
- **Отдача** — проверка `room_token` при скачивании
- Лимит загрузки — **50 MB**, изображения декодируются и проверяются (защита от декомпрессионных бомб)

#### 🖥️ Современный интерфейс

- **Свой видеоплеер** — кастомные контролы в фирменном стиле: seek-бар с превью времени и буфером, ±10с, громкость, скорость (1–2×), fullscreen; автоскрытие контролов, горячие клавиши (Space/K, ←/→, J/L, ↑/↓, M, F, 0–9), скачивание видео с оригинальным именем
- **Лайтбокс для фото** — полноэкранный просмотр с зумом (кнопки/колесо/клик), панорамированием, навигацией по всем фото комнаты (←/→), счётчиком и скачиванием
- **Полноэкранный режим** — плавная анимация перехода, сайдбар скрывается/показывается
- **Мобильная версия** — переключение экранов «комнаты ↔ чат» свайп-анимацией, tap-меню вместо контекстного
- **Прогресс-бар загрузки** файлов с возможностью отмены
- **Контекстное меню** сообщений (ПКМ на десктопе, тап на мобильных)
- **Подсветка ответов** — клик по цитате скроллит к сообщению и подсвечивает его пульсирующим свечением
- **Уведомления браузера** — опциональные desktop-уведомления
- **SVG-иконки** — единый набор иконок во всём интерфейсе, золотые админ-бейджи с короной

#### 👑 Ролевая модель

- **Пользователь** — может создавать комнаты, общаться, загружать файлы, редактировать свои сообщения
- **Администратор** — дополнительно может удалять любые сообщения и комнаты, входить в комнаты без пароля, обходит rate-limit
- Создатель комнаты имеет права на её удаление

#### 🌍 Интернационализация

- Поддержка русского и английского языков
- Переключение «на лету» без перезагрузки
- Локализованы все элементы интерфейса, системные сообщения и даже ошибки API (включая ошибки валидации полей)

## 🚀 Быстрый старт

### 📋 Предварительные требования

- **Python** `3.10` или выше
- **Node.js** `18` или выше (для сборки фронтенда)
- **pip** (менеджер пакетов Python)
- **Git** (для клонирования репозитория)

### 🔽 Установка

#### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/Filldor2033/LESogram.git
cd LESogram
```

#### 2️⃣ Сборка фронтенда (Svelte → dist/)

```bash
cd frontend
npm install
npm run build        # прод-сборка в frontend/dist
```

> 💡 Для разработки: `npm run dev` поднимет Vite на `http://localhost:5173` с прокси `/api` и `/ws` на бэкенд.

#### 3️⃣ Создание виртуального окружения

**Linux / macOS:**

```bash
cd ..
python -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

#### 4️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

#### 5️⃣ Запуск приложения

```bash
cd src
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

#### 6️⃣ Открытие в браузере

Перейдите по адресу: **[http://localhost:8000](http://localhost:8000)**

- `/` — новый Svelte-интерфейс
- `/legacy` — старый JS-интерфейс (для сравнения)
- `/docs` — автодокументация OpenAPI

> ⚠️ Если фронтенд не собран (`frontend/dist` отсутствует), `/` автоматически отдаст legacy-версию.

## 📖 Использование

### 🔐 Аутентификация

| Действие        | Описание                                                     |
| :-------------- | :----------------------------------------------------------- |
| **Регистрация** | Создайте аккаунт, указав имя пользователя (3–50 символов: буквы латиницы/кириллицы, цифры, `_ . -` и пробелы) и пароль (4–72 символа) |
| **Вход**        | Войдите в существующий аккаунт для получения токена доступа  |

> 💡 При неудачной регистрации форма показывает конкретную причину (слишком короткий логин, недопустимые символы и т.д.) и блок с требованиями к логину и паролю.

> 👑 **Администраторы:** первый зарегистрированный пользователь не становится администратором автоматически. Чтобы сделать пользователя администратором, измените поле `is_admin` на `1` в таблице `users` базы данных.

### 🏠 Комнаты

| Действие       | Описание                                                     |
| :------------- | :----------------------------------------------------------- |
| **Создание**   | Нажмите "Create room", указав название (3–100 символов) и пароль (3–72 символа) |
| **Поиск**      | Используйте поля поиска по названию или создателю            |
| **Фильтрация** | Отфильтруйте комнаты: все / с пользователями / пустые        |
| **Сортировка** | Отсортируйте по названию, количеству онлайн или создателю    |
| **Вход**       | Введите пароль комнаты и нажмите "Join"                      |
| **Удаление**   | Доступно создателю комнаты или администратору                |

> 👑 **Администраторы** могут входить в любую комнату без пароля!

### 💬 Чат

| Действие                 | Описание                                                       |
| :----------------------- | :------------------------------------------------------------- |
| **Отправка текста**      | Введите сообщение и нажмите `Enter` или кнопку со стрелкой     |
| **Реакции / Ответ / Редактирование** | ПКМ по сообщению (или тап на мобильном) → контекстное меню |
| **Переход к ответу**     | Клик по цитате → скролл к сообщению + зелёная подсветка        |
| **Упоминания**           | Введите `@` и начните печатать имя — появится автодополнение   |
| **Фото**                 | Клик по фото → лайтбокс: зум, панорамирование, ←/→ между фото  |
| **Видео**                | Свой плеер: клик = пауза, двойной клик = fullscreen            |
| **Хоткеи плеера**        | `Space`/`K` play-pause · `←`/`→` ±5с · `J`/`L` ±10с · `↑`/`↓` громкость · `M` mute · `F` fullscreen · `0–9` переход |
| **Фото / Видео / Файл**  | Кнопка со скрепкой → выбор файла → прогресс-бар с отменой      |
| **Полноэкранный режим**  | Кнопка «Expand» в тулбаре чата (только десктоп)                |
| **Онлайн-пользователи**  | Кнопка с иконкой людей в тулбаре чата                          |
| **Уведомления**          | Кнопка колокольчика включает desktop-уведомления               |
| **Выход**                | Нажмите "Exit chat" для выхода из комнаты                     |

### 📱 Мобильная версия

Интерфейс автоматически перестраивается на узких экранах:

- Два экрана вместо колонок: **список комнат ↔ чат** с анимированным переключением
- Кнопка «назад» в чате для возврата к списку комнат
- **Тап по сообщению** открывает контекстное меню (вместо ПКМ)

### 🌍 Смена языка

Нажмите **EN** или **RU** в правом верхнем углу для переключения между английским и русским языками.

## 🔌 API-эндпоинты

> Новый фронтенд обращается к REST-эндпоинтам с префиксом `/api/*`. Все эндпоинты также доступны без префикса (для совместимости). WebSocket всегда без префикса.

### 🔑 Аутентификация

| Метод  | Эндпоинт          | Описание                          | Требует токен |
| :----- | :---------------- | :-------------------------------- | :-----------: |
| `POST` | `/api/register`   | Регистрация нового пользователя   |       ❌       |
| `POST` | `/api/login`      | Вход в систему                    |       ❌       |
| `GET`  | `/api/me`         | Информация о текущем пользователе |   ✅ Bearer    |

### 🏠 Комнаты

| Метод    | Эндпоинт                    | Описание                                | Требует токен |
| :------- | :-------------------------- | :-------------------------------------- | :-----------: |
| `GET`    | `/api/rooms`                | Список всех комнат                      |   ✅ Bearer    |
| `POST`   | `/api/rooms`                | Создание новой комнаты                  |   ✅ Bearer    |
| `POST`   | `/api/rooms/join`           | Присоединение к комнате (даёт room_token) |  ✅ Bearer |
| `GET`    | `/api/rooms/{room}/users`   | Пользователи в комнате                  |    ✅ Room     |
| `DELETE` | `/api/rooms/{room_name}`    | Удаление комнаты (создатель/админ)      |   ✅ Bearer    |

### 💬 Сообщения

| Метод     | Эндпоинт                                | Описание                                   | Требует токен |
| :-------- | :-------------------------------------- | :----------------------------------------- | :-----------: |
| `GET`     | `/api/messages/{room}`                  | История сообщений (последние 50)           |    ✅ Room     |
| `DELETE`  | `/api/messages/{message_id}`            | Удаление сообщения (только админ)          |   ✅ Bearer    |
| `PATCH`   | `/api/messages/{message_id}`            | Редактирование своего сообщения            |   ✅ Bearer    |
| `POST`    | `/api/messages/{message_id}/reactions`  | Поставить/убрать реакцию (6 эмодзи)        |   ✅ Bearer    |

### 📎 Вложения

| Метод  | Эндпоинт                        | Описание                                |    Требует токен    |
| :----- | :------------------------------ | :-------------------------------------- | :-----------------: |
| `POST` | `/api/rooms/{room}/attachments` | Загрузка файла в комнату (до 50 MB)     | ✅ Bearer + Room    |
| `GET`  | `/attachments/{message_id}`     | Скачивание/просмотр файла               |      ✅ Room        |

### 🔗 WebSocket

| Протокол | Эндпоинт                        | Описание                               |
| :------- | :------------------------------ | :------------------------------------- |
| `WS`     | `/ws/{room}?room_token=<token>` | Соединение для чата в реальном времени |

Протокол сообщений клиента → сервер:

```jsonc
{ "type": "message",  "text": "привет", "reply_to_id": 12 }  // сообщение (опц. ответ)
{ "type": "typing" }                                          // статус «печатает…»
```

Сервер → клиент: `message`, `system` (вход/выход), `typing`, `mention`, `edit`, `delete`, `reaction`.

## 🔒 Безопасность

### 🛡️ Реализованные меры защиты

| Мера                            | Описание                                                     |
| :------------------------------ | :----------------------------------------------------------- |
| **JWT-токены**                  | Двухуровневая система: `access_token` для API и `room_token` для комнат |
| **Хеширование паролей**         | Используется алгоритм Argon2 через библиотеку Pwdlib         |
| **Rate limiting**               | Скользящее окно с разными лимитами: register 8/мин, login 10/мин, создание комнат и загрузка файлов 20/5мин, правка сообщений 60/мин, реакции 120/мин, burst-защита WebSocket 5 сообщений/3с |
| **WebSocket Origin**            | Проверка Origin заголовка для WebSocket-соединений           |
| **Защита от опасных файлов**    | Чёрный список расширений (`.exe`, `.js`, `.php` и др.) и MIME-типов |
| **Белые списки файлов**         | Разрешены только безопасные типы изображений, видео, аудио и документов |
| **Проверка изображений**        | Декодирование через Pillow, лимит 20 Мп (защита от декомпрессионных бомб) |
| **Безопасные имена файлов**     | Файлы сохраняются со случайными именами                      |
| **Защита от Path Traversal**    | Проверка путей при отдаче файлов                             |
| **HTTP-заголовки безопасности** | CSP, HSTS, X-Content-Type-Options, X-Frame-Options и др.     |
| **Ограничение размера**         | Максимальный размер загружаемого файла: 50 MB                |
| **Валидация входных данных**    | Pydantic-схемы на всех эндпоинтах, строгие регулярные выражения для имён |
